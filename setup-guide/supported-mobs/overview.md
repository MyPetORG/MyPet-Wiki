# Overview

Use this page as the index for all pet pages.

In this docs section:

* A **mob** is a vanilla Minecraft entity type (e.g. Wolf, Zombie).
* A **Pet** is a mob that MyPet can tame and manage.

{% hint style="info" %}
Versions listed here refer to **MyPet** versions. Not Minecraft versions.
{% endhint %}

### Add a new Pet

1. Duplicate **Pet Page Template**.
2. Rename it to the Pet’s name.
3. Add the mob type to the supported Pets table.
4. Fill in the version where support was added.
