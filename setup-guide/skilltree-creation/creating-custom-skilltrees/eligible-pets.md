# Eligible Pets

<figure><img src="../../.gitbook/assets/Skilltree Pets.png" alt="" width="563"><figcaption></figcaption></figure>

The `Eligible Pets` section of the [Configurator's](./) Inspector allows you to configure which pets can use the current skilltree. All pets, including pets from future Minecraft updates, are included by default. Deselect the checkbox to limit the skilltree to extant pet types. A `Deselect All` button is also provided if you'd like to start from scratch and select each pet individually.
