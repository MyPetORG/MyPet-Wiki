# Pickup

With this skill your pet can pickup grounded items and XP like a player. The items are added to the [backpack](backpack.md) of the pet. This skill can not be activated when the pet doesn't have the Backpack skill with at least 1 row.

Pickup can be enabled/disabled by using the `/petpickup` [command](https://wiki.mypet-plugin.de/setup/commands#skill-commands).
