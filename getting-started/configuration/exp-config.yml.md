# exp-config.yml

## Type — Description

**Default:**\
[**ENTITY\_TYPE**](https://jd.papermc.io/paper/1.21.11/org/bukkit/entity/EntityType.html)**:**

* **`Min:`**\
  Type: double\
  Description: The minimal amount of XP that this entity type grants.
* **`Max:`**\
  Type: double\
  Description: The maximum amount of XP that this entity type grants.

* **`Max:`**\
  Type: double\
  Description: The maximum amount of XP that this entity type grants.

**`'[MythicMobs]=<Typename>'`:**

* **`Min:`**\
  Type: double\
  Description: The minimal amount of XP that this entity type grants.
* **`Max:`**\
  Type: double\
  Description: The maximum amount of XP that this entity type grants.
