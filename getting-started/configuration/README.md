# Configuration

### Go to:

* [config.yml](config.yml.md) - MyPet's main config file.
* [pet-config.yml](pet-config.yml.md) - Contains options for pet types.
* [pet-shops.yml](pet-shops.yml.md) - Contains options for pet shops.
* [hooks-config.yml](hooks-config.yml.md) - Contains options for plugin hooks.
* [exp-config.yml](exp-config.yml.md) - Contains options for how experience is gained.
* [worldgroups.yml](worldgroups.yml.md) - Configures how pets work across worlds.
* [Custom-Item-Data in Config](custom-item-data-in-config.md) - Configures how MyPet interacts with specific items.
